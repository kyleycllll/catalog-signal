# Evidence checklist

After running the Colab notebook, preserve these Drive artifacts in a portfolio release:

- `esci-qwen-lora/adapter_model.safetensors`
- `esci-qwen-lora/adapter_config.json`
- `esci-comparison.json`
- `esci-predictions.jsonl`
- `esci-training-metadata.json`
- `reports/experiments/<run>/results.json` and `comparison.md`
- A screenshot of the React UI displaying `LoRA online`
- The ESCI data manifest generated by `scripts/prepare_esci.py`

The comparison JSON is the source of truth for before/after classifier claims. Report its sample size, seed, selected training variant, frozen-base macro-F1, LoRA macro-F1, and delta together. The experiment report is the source of truth for retrieval/reranking and latency claims.
